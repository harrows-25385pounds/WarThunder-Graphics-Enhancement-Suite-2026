## Frequently Asked Questions

**Q: Is this tool safe to use? Will it trigger anti-cheat systems?**
A: This suite operates exclusively by editing configuration files and modifying interface elements, not by interacting with the game's memory. It does not provide any gameplay advantage and is designed for customization. However, users should always review the game's terms of service.

**Q: My antivirus software flags the installer. Is this normal?**
A: Some security software may issue warnings about applications that modify game settings. This is a false positive. The source code is publicly available for review, and you can always scan the file before installation.

**Q: Can I use this on multiple computers?**
A: Yes. The configuration profiles you create are portable files. You can back them up and load them on another Windows PC that has War Thunder installed, provided you also install the Graphics Enhancement Suite there.

**Q: Will this work with the Steam or standalone War Thunder launcher?**
A: The suite supports both versions. During installation, it will attempt to automatically locate your War Thunder installation directory. If it fails, you can manually point it to the correct folder (where `aces.exe` is located).

**Q: Do I need to run the suite every time I play?**
A: No. Once you have applied and saved your settings, they persist in the game's configuration files. The suite only needs to be running if you wish to change your settings.
